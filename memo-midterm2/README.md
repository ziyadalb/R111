الكتابة Markdown عادي، والرياضيات LaTeX بين `$...$` (في السطر) أو `$$...$$` (سطر مستقل).

أوامر خاصة داخل ملفات الشرح:
- `@example M451-1-1` يعرض حل السؤال الكامل كمثال.
- `::: diff M452-1-1` … `:::` بطاقة «وش يختلف».
- `::: box steps عنوان` … `:::` صندوق ملوّن (الأنواع: recog, first, steps, why, warn, fix, short, more, alg, law, note, use, scope).
- `@toc` و`@cover`، وفي ملف 4.2 بعد: `@chart`. وفي ملفات 5.1 و5.2 و5.3 و6.1: `@pattern P1` (عنوان النمط ووسومه) و`@formula`.
- في ملف 5.3: `@tri مقابل|مجاور|وتر` يرسم المثلث (يشتغل داخل الحلول كمان)، و`@tris` الثلاث مثلثات، و`@checks T1` أسئلة الفهم، و`@practice T1` أسئلة النمط للتدريب.

## البناء

```bash
npm install
node build/build-42.mjs        # ملف 4.2
node build/build-5x.mjs        # ملف 5.1 و5.2
node build/build-53.mjs        # ملف 5.3
node build/build-61.mjs        # ملف 6.1
```

يحتاج Chromium عن طريق Playwright، وPython مع `pypdf` (يكتب الفهرس الجانبي بعناوين عربية صحيحة).

## التحقق من الأجوبة

```bash
pip install sympy mpmath pyyaml
python3 verify/verify.py       # التقرير في verify/report.md
```

كل جواب يُشتق ويُقارن بالسؤال عدديًا في نقاط من كل جهة من المجال، وصيغ المفاتيح المطبوعة الغلط تُفحص إنها تغلط فعلًا. وكل متطابقة واختصار في الشرح لها فحص في نفس الملف.
