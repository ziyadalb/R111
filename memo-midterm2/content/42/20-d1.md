# <span class="num">2</span> المشتقات

<p class="lede">السؤال الأول في كل فصلي: مشتقتين، كل وحدة درجتين أو درجة. وفي 4 نهائيات من 6 جات مشتقة في السؤال 1 فقرة 3. كلها نفس الوصفة، والفرق في الطبقات اللي تجي معها.</p>

::: box steps الوصفة: خمس خطوات لكل مشتقة
1. **قسّم على الجمع:** كل حد تشتقه لحاله.
2. **رتّب الطبقات من برّا لجوّا:** قوة؟ $\ln$؟ بعدين اسم الدالة، بعدين الداخل.
3. **اكتب مشتقة الداخل على جنب** قبل القانون. أغلب الأخطاء من نسيانها.
4. **طبّق القانون:** الداخل يبقى زي ما هو داخل القانون، وتضرب في مشتقته.
5. **بسّط، واكتب المجال:** ربّع الداخل، واشطب العوامل، وكل دالة عكسية تحط شرط على داخلها.
:::

@pattern D1

::: box recog كيف تعرفه وأول حركة
**تعرفه:** حد أو حدين، كل واحد دالة زائدية أو زائدية عكسية، وداخلها شي مو $x$ لحاله: $5x^2$، $\sqrt x$، $e^{5x}$، $\sin x$، $\ln|x+1|$.

**أول حركة:** اكتب الداخل ومشتقته (ومربعه لو الدالة عكسية) قبل أي شي.
:::

@example M471-1-2

::: box short اختصار: في $\sech^{-1}(kx)$ الـ $k$ تنشطب
$$\frac{d}{dx}\sech^{-1}(kx)=\frac{-k}{kx\sqrt{1-k^2x^2}}=\frac{-1}{x\sqrt{1-k^2x^2}}$$
جاء مرتين: $\sech^{-1}(2x)$ في M451-1-1، و$\sech^{-1}(3x)$ في M452-1-1.
:::

@checks D1

<div class="h3 diffs-title">باقي الأسئلة: وش يختلف؟</div>

::: diff M451-1-1
$\cosh$ مشتقتها $\sinh$ بدون سالب. و$\sech^{-1}(2x)$ بالاختصار: $\frac{-1}{x\sqrt{1-4x^2}}$.
:::

::: diff M452-1-1
$\tanh$ مشتقتها $\sech^2$، والداخل $2x^3$ مشتقته $6x^2$. و$\sech^{-1}(3x)$ بالاختصار.
:::

::: diff M461-1-1
داخل $\csch$ هو $\frac2x$ ومشتقته سالبة، ومشتقة $\csch$ فيها سالب: سالب في سالب = موجب. وفي $\tanh^{-1}\big(e^{5x}\big)$ المربع $e^{10x}$، والشرط $e^{5x}<1$ يعني $x<0$.
:::

::: diff M461-1-2
داخل $\sinh^{-1}$ جذر: مشتقته $\frac{1}{2\sqrt x}$، ومربعه $x$. و$\coth$ مشتقتها $-\csch^2$.
:::

::: diff M462-1-2
$\coth^{-1}$ نفس قانون $\tanh^{-1}$ بدون سالب، ويطلع كسر داخل كسر: اضرب فوق وتحت في 9.
:::

::: diff M471-1-1
داخل $\sinh$ جذر، ومشتقته $\frac{x}{\sqrt{x^2+1}}$. وداخل $\cosh^{-1}$ هو $e^x$، ومربعه $e^{2x}$.
:::

::: diff M472-1-1
دالة وحدة، والداخل $\ln|x+1|$ ومشتقته $\frac{1}{x+1}$. لا تشتق $\ln$ اللي داخل الجذر: هو الداخل نفسه.
:::

::: diff M472-1-2
قانون $\csch^{-1}$ فيه $|f|$، بس الداخل جذر وموجب، فتكتبه هو نفسه. وجذر في نفسه يعطي اللي تحته.
:::
