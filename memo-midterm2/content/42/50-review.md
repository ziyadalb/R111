# <span class="num">5</span> قبل التدريب: أخطاء شائعة وورقة مراجعة

<div class="h3">أخطاء شائعة: شيك عليها في كل حل</div>

| الغلط | الصح |
|---|---|
| تنسى مشتقة الداخل $u'$ | كل قانون مضروب في $u'$ |
| $\sinh^{-1}x=\frac{1}{\sinh x}$ | العكسية ترجّع، والمقلوب $\csch x$ |
| سالب زايد في مشتقة $\coth^{-1}$ | $\frac{u'}{1-u^2}$ نفس $\tanh^{-1}$ |
| تشيل $\lvert u\rvert$ من $\csch^{-1}$ أو $\sech^{-1}$ | ما تشيلها إلا إذا $u$ موجب أكيد |
| $\cosh^{-1}$ والمجال فيه جهة سالبة | الصيغة اللوغاريتمية $\ln\lvert u+\sqrt{u^2-a^2}\rvert$ |
| $a^2=2$ تكتب $a=2$ | $a=\sqrt2$ |
| إكمال بمعامل سالب وتنسى قلب الإشارة | اللي تضيفه داخل $-(\dots)$ يطلع برّا موجب |
| نصف تعويض: يبقى $x$ في التكامل | حوّل كل شي لـ $u$، حتى $dx$ والعوامل |
| تنسى $\ln5$ في مشتقة $5^x$ | $\big(a^w\big)'=a^w\ln a\cdot w'$ |
| تخلط $\frac{du}{u^2+a^2}$ مع $\frac{du}{\sqrt{u^2+a^2}}$ | الأول $\tan^{-1}$، الثاني $\sinh^{-1}$ |
| تشطب من حد جمع | الشطب بين عوامل بس |
| سالب في تكامل $\sinh$ | $\int\sinh=\cosh$ و$\int\cosh=\sinh$ بدون سالب |

<div class="h3">ورقة المراجعة</div>

::: box law المشتقات
$$\begin{aligned}
(\sinh^{-1}u)'&=\frac{u'}{\sqrt{1+u^2}} & (\cosh^{-1}u)'&=\frac{u'}{\sqrt{u^2-1}}\\[2pt]
(\tanh^{-1}u)'&=\frac{u'}{1-u^2} & (\coth^{-1}u)'&=\frac{u'}{1-u^2}\\[2pt]
(\sech^{-1}u)'&=\frac{-u'}{u\sqrt{1-u^2}} & (\csch^{-1}u)'&=\frac{-u'}{|u|\sqrt{1+u^2}}
\end{aligned}$$
اختصار المقلوب:
$$\csch^{-1}w=\sinh^{-1}\tfrac1w,\qquad\sech^{-1}w=\cosh^{-1}\tfrac1w$$
:::

::: box law التكاملات
$$\begin{aligned}
\int\frac{du}{\sqrt{u^2+a^2}}&=\sinh^{-1}\frac ua\\[2pt]
\int\frac{du}{\sqrt{u^2-a^2}}&=\ln\big|u+\sqrt{u^2-a^2}\big|\\[2pt]
\int\frac{du}{a^2-u^2}&=\frac1a\tanh^{-1}\frac ua, && |u|<a\\[2pt]
\int\frac{du}{u\sqrt{a^2-u^2}}&=-\frac1a\sech^{-1}\frac{|u|}a\\[2pt]
\int\frac{du}{u\sqrt{a^2+u^2}}&=-\frac1a\csch^{-1}\frac{|u|}a
\end{aligned}$$
:::

::: box steps أول حركة لكل نمط
1. **مشتقة:** رتّب الطبقات من برّا لجوّا، واكتب $u'$ قبل القانون.
2. **حد خطي تحت الجذر:** كمّل المربع، والإشارة تختار القانون.
3. **$(x-c)$ برّا الجذر:** كمّل المربع (طلّع السالب أول)، فيطلع $\sech^{-1}$ أو $\csch^{-1}$.
4. **الداخل ومشتقته موجودين:** عوّض مباشرة، واضرب واقسم على الثابت الناقص.
5. **المشتقة مو ظاهرة:** عوّض واكتب $dx$ كامل، أو اضرب فوق وتحت في العامل الناقص.
6. **تكامل زائدي (4.1):** عوّض الداخل، وطبّق قانون 4.1.
:::
