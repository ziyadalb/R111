# <span class="num">2</span> الأنماط الأربعة

<p class="lede">تعرف النمط من اللي تحت الجذر. في كل نمط: كيف تعرفه، ومثال كامل من الاختبارات، وأسئلة فهم بأجوبتها، ووش يختلف في باقي أسئلته. وتحته أسئلته كلها تتدرب عليها، ولكل سؤال رابط لحله.</p>

@pattern T1

::: box recog كيف تعرفه وأول حركة
**تعرفه:** رقم ناقص $x^2$، تحت الجذر أو تحت القوس: $a^2-x^2$.

**أول حركة:** $x=a\sin\theta$، و$dx=a\cos\theta\,d\theta$، والجذر يصير $a\cos\theta$. والمثلث: المقابل $x$ والوتر $a$، والمجاور هو الجذر.
:::

@checks T1

<div class="h3 diffs-title">باقي الأسئلة: وش يختلف؟</div>

::: diff M462-2-6
نفس المثال بالضبط، بس $a=3$. الأرقام بس تتغير: $9^{3/2}=3^3=27$ بدل 8.
:::

::: diff F472-2-5
$x^2$ تحت مع الجذر. بعد الشطب يطلع $\csc^2\theta$، وتكامله $-\cot\theta$:
$$\frac19\int\frac{d\theta}{\sin^2\theta}=\frac19\int\csc^2\theta\,d\theta$$
وترجع بـ $\cot\theta$ = المجاور على المقابل. ونفسه مثال 1 في المذكرة، مع $a=4$.
:::

::: diff F471-2-5
$x^2$ فوق والقوس تحت. بعد التبسيط يطلع $\tan^2\theta$، وما له قانون مباشر، فحوّله:
$$\int\tan^2\theta\,d\theta=\int\big(\sec^2\theta-1\big)\,d\theta=\tan\theta-\theta$$
وبقت $\theta$ في الجواب: ترجعها من التعويض، $\theta=\sin^{-1}\frac x2$. ونفسه تمرين 9، مع $a=1$.
:::

::: diff n53e5
كل شي ينشطب ويبقى $\int d\theta=\theta$. فالجواب هو $\theta$ نفسها، ترجعها من التعويض.
:::

::: diff n53x1
الجذر فوق و$x^2$ تحت، فيطلع $\cot^2\theta$. نفس فكرة $\tan^2\theta$:
$$\int\cot^2\theta\,d\theta=\int\big(\csc^2\theta-1\big)\,d\theta=-\cot\theta-\theta$$
:::

::: diff n53x6
الجذر لحاله، فيطلع $36\cos^2\theta$. قوة زوجية، نخفّضها (من 5.2):
$$\cos^2\theta=\frac{1+\cos2\theta}{2}$$
وبعد التكامل اكتب $\sin2\theta=2\sin\theta\cos\theta$، عشان تقدر ترجع بالمثلث.
:::
