# <span class="num">2</span> الأنماط الثلاثة

<p class="lede">تعرف النمط من شكل الجذر: قوى كسرية لـ $x$ نفسه، أو جذر فوقه جذر، أو $e^x$ تحت الجذر. في كل نمط: كيف تعرفه، ومثال كامل، وأسئلة فهم، ووش يختلف في باقي أسئلته. وتحته أسئلته كلها للتدريب، ولكل سؤال رابط لحله.</p>

@pattern H1

::: box recog كيف تعرفه وأول حركة
**تعرفه:** في المقام (أو البسط) قوى كسرية لـ $x$ نفسه: $\sqrt x$ و$\sqrt[3]x$ و$x^{2/3}$... وما فيه مشتقة جاهزة.

**أول حركة:** $n$ = المضاعف المشترك الأصغر لمقامات الأسس، و$x=t^n$، و$dx=nt^{n-1}\,dt$. بعدين نظّف وكامل بالجدول.
:::

@example M472-3-7

@checks H1

<div class="h3 diffs-title">باقي الأسئلة: وش يختلف؟</div>

::: diff M471-2-9
المقامات 2 و3: $n=6$ مو 3. وبعد التنظيف يطلع $\frac{t^2}{t+1}$.
:::

::: diff M451-2-9
$\sqrt[4]x$ و$\sqrt x$: $n=4$، وبعد التنظيف $\frac{t^2}{t+1}$.
:::

::: diff F451-2-5
$n=6$، وبعد التنظيف $\frac{t^3}{t+1}$: القسمة المتناوبة بثلاث قوى. وفي المفتاح غلطة في الجواب النهائي، مكتوبة تحت الحل.
:::

::: diff F452-2-5
$x$ و$\sqrt[3]x$: $n=3$، والمقام يطلع $t^2+1$ مو $t+1$. والبسط $t$ نص مشتقته، فتكامله $\ln$ مباشرة.
:::

::: diff F461-2-5
ما يحتاج تبديل: $\frac{1}{2\sqrt x}$ مشتقة $\sqrt x$، والشكل $\frac{f'}{1+f^2}$ تكامله $\tan^{-1}f$.
:::

::: diff n55e1-2
$n=6$، والمقام بعد التنظيف $t^2+1$ والبسط $t^4$: قسمة على $t^2+1$، ويطلع $\tan^{-1}$.
:::

::: diff n55x1
$n=6$، وبعد التنظيف $\frac{t^4}{t+1}$: القسمة المتناوبة بأربع قوى.
:::

::: diff n55x7
فيه $\sqrt x$ فوق وتحت، فـ $n=2$. وبعد التبديل يطلع كسر $\frac{t-t^2}{t+1}$ تقسمه.
:::

::: diff n55x2
$x^{1/4}$ و$x^{1/3}$: $n=12$. وبعد التنظيف $\frac{t^8}{t+1}$: نفس القسمة المتناوبة، بس طويلة.
:::

::: diff n55x3
$n=10$، والمقام يطلع $t^3+1$. هذا أطول من أي سؤال اختبار، فخله آخر شي.
:::
