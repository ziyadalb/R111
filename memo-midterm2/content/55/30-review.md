# <span class="num">3</span> قبل الاختبار: كيف تختار؟ وأخطاء شائعة

<div class="h3">اسأل نفسك: وش شكل الجذر؟</div>

| تشوف | سوّ | النمط |
|---|---|---|
| مشتقة الداخل موجودة (مثل $\frac{1}{\sqrt x}$ مع دالة في $\sqrt x$) | القوة العكسية، بدون تبديل | الأساس |
| قوى كسرية لـ $x$ بس | $x=t^n$، و$n$ = المضاعف المشترك للمقامات | 1 |
| جذر فوقه جذر | $t$ = الجذر الخارجي كله، و$x=\big(t^2-a\big)^2$ | 2 |
| $e^x$ تحت الجذر | $t$ = الجذر كله، و$x=\ln\big(t^2\mp1\big)$ | 3 |

<div class="h3">أخطاء شائعة: شيك عليها في كل حل</div>

| الغلط | الصح |
|---|---|
| تختار $n$ أكبر مقام (2 و3 تاخذ 3) | المضاعف المشترك: 6 |
| تنسى $dx=nt^{n-1}\,dt$ | يتعوّض مع الباقي |
| تشطب حدود جمع: $\frac{t^3}{t^2+t}=t$ | طلّع العامل المشترك أول: $\frac{t^3}{t(t+1)}=\frac{t^2}{t+1}$ |
| $\frac{t^2}{t+1}=t+\frac{1}{t+1}$ | $t-1+\frac{1}{t+1}$: تأكد بالضرب |
| ترجع $t^2$ لـ $x^{2/6}$ وتوقف | بسّط: $x^{1/3}$ |
| في $\sqrt{4+\sqrt x}$ تبدّل $\sqrt x$ بس | بدّل الجذر الخارجي كله |
| في $t=\sqrt{4+\sqrt x}$ تكتب $x=t^2-4$ | $x=\big(t^2-4\big)^2$: ربّع مرتين |
| تترك الجواب بـ $t$ | لازم يرجع بـ $x$ |

<div class="h3">ورقة المراجعة</div>

::: box law كل اللي تحتاجه في صندوق
**الخطوة صفر:** مشتقة الداخل موجودة؟ القوة العكسية بدون تبديل.

**النمط 1:** $x=t^n$، و$dx=nt^{n-1}\,dt$، و$n$ = المضاعف المشترك لمقامات الأسس.

**النمط 2:** $t=\sqrt{a+\sqrt x}$، و$x=\big(t^2-a\big)^2$، و$dx=4t\big(t^2-a\big)dt$.

**النمط 3:** $t=\sqrt{e^x\pm1}$، و$x=\ln\big(t^2\mp1\big)$، و$dx=\frac{2t}{t^2\mp1}\,dt$.

**بعد التبديل:**
$$\frac{t}{t+1}=1-\frac{1}{t+1},\qquad\frac{t^2}{t+1}=t-1+\frac{1}{t+1},\qquad\frac{t^3}{t+1}=t^2-t+1-\frac{1}{t+1}$$
$$\int\frac{dt}{t^2+1}=\tan^{-1}t,\qquad\int\frac{t\,dt}{t^2+1}=\frac12\ln\big(t^2+1\big),\qquad\int\frac{2\,dt}{t^2-1}=\ln\Big|\frac{t-1}{t+1}\Big|$$
:::
