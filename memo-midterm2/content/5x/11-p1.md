@pattern P1

::: box recog
كثير حدود ($x$، $2x+1$، $x^2$…) مضروب في دالة تكاملها سهل: $\cos$، $\sin$، $\sinh$، $\cosh$، $e^{kx}$، أو $\sec^2x$.
:::

::: box first
$u$ = كثير الحدود، و$dv$ = الباقي. كل تجزئة تنزّل درجته واحد، فالتكامل الجديد أسهل من اللي قبله.
:::

@example M452-2-2

<div class="h3 diffs-title">باقي أسئلة الفصلي: وش يختلف؟</div>

::: diff M461-2-4
نفس المثال، بس مع $\sinh x$. تكامل $\sinh$ هو $\cosh$ (بدون سالب)، وتكامل $\cosh$ هو $\sinh$:
$$u=3x-2,\qquad v=\cosh x$$
$$(3x-2)\cosh x-\int3\cosh x\,dx=(3x-2)\cosh x-3\sinh x+C$$
:::

::: diff M462-2-3
نفس M461-2-4 مع $\cosh x$، فـ $v=\sinh x$:
$$(2x-1)\sinh x-\int2\sinh x\,dx=(2x-1)\sinh x-2\cosh x+C$$
:::

<div class="h3">الدرجة 2 أو أكثر: جزّئ أكثر من مرة</div>

درجة كثير الحدود = كم مرة تجزّئ. $x^2$ يبي مرتين: الأولى تنزّله لـ $x$، والثانية تخلّصه. وفي كل مرة **نفس الاختيار**: كثير الحدود هو $u$. هذا جاء في نهائي 1447 ونهائي 1445، وكل واحد عليه 3 درجات.

@example F471-2-2

::: diff F451-2-2
نفس المثال مع $\cosh x$، وما فيه قسمة على 3. انتبه للسالب قدّام القوس:
$$\int x^2\cosh x\,dx=x^2\sinh x-2\int x\sinh x\,dx$$
$$=x^2\sinh x-2\big(x\cosh x-\sinh x\big)=x^2\sinh x-2x\cosh x+2\sinh x+C$$
:::

::: box short اختصار: طريقة الجدول (بشرطه)
**الشرط:** واحد من الاثنين كثير حدود (مشتقاته توصل صفر)، والثاني تقدر تكامله كذا مرة ورا بعض: $e^{kx}$ أو $\sin$ أو $\cos$ أو $\sinh$ أو $\cosh$. لو الشرط ما انطبق (مثل $\ln$، أو $e^x\sin x$) لا تستخدمه.

عمود تشتق فيه كثير الحدود لين يصير صفر، وعمود تكامل فيه الثاني، والإشارات تتبدّل: $+$ بعدها $-$ بعدها $+$. مثلًا F471-2-2:

<div class="tabular-wrap">

| الإشارة | نشتق | نكامل |
|:-:|:-:|:-:|
| $+$ | $x^2$ | $\cos3x$ |
| $-$ | $2x$ | $\frac13\sin3x$ |
| $+$ | $2$ | $-\frac19\cos3x$ |
| | $0$ | $-\frac1{27}\sin3x$ |

</div>

اضرب كل خانة من «نشتق» في الخانة **اللي تحتها** من «نكامل»، بإشارة سطرها:
$$+x^2\Big(\tfrac13\sin3x\Big)-2x\Big(-\tfrac19\cos3x\Big)+2\Big(-\tfrac1{27}\sin3x\Big)+C$$
نفس جواب التجزئة مرتين. وتمرين 3 في المذكرة ($x^3e^x$) يبي 3 مرات، والجدول يختصرها لك.
:::

<div class="h3 diffs-title">من المذكرة: وش يختلف؟</div>

::: diff n51x4
$dv=\sec^2x\,dx$ لأن تكاملها $\tan x$. وبعد القانون يطلع لك $\int\tan x\,dx$، وهذا قانون جاهز:
$$\int\tan x\,dx=-\ln|\cos x|$$
:::

::: diff n51x2
تكامل $\sin2x$ فيه سالب وقسمة على 2، والسالبين يصيرون موجب:
$$v=-\tfrac12\cos2x,\qquad-\int v\,du=-\int\Big(-\tfrac12\cos2x\Big)2x\,dx=+\int x\cos2x\,dx$$
:::
