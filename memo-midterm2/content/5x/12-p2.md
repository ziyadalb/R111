::: box recog
$\ln$ مضروب في قوة $x^n$ (حتى لو $n$ سالب)، أو $\ln$ لحاله.
:::

::: box first
$u=\ln$ دايم. مشتقته $\frac1x$ تمسح اللوغاريتم، وتنشطب مع القوة. و$dv$ = القوة، أو $dx$ لو $\ln$ لحاله.
:::

@example M471-2-7

<div class="h3 diffs-title">باقي أسئلة الفصلي والنهائي: وش يختلف؟</div>

::: diff M452-2-5
نفس المثال، و$x$ بدل $x^3$:
$$v=\frac{x^2}{2},\qquad\frac{x^2}{2}\ln|x|-\frac12\int x\,dx=\frac{x^2}{2}\ln|x|-\frac{x^2}{4}+C$$
:::

::: diff M461-2-5
الأس سالب. تكامل $x^{-2}$: الأس يصير $-1$ ونقسم عليه، فيطلع $v$ بسالب:
$$v=\frac{x^{-1}}{-1}=-\frac1x$$
وبعدها سالب في سالب = موجب:
$$\int x^{-2}\ln x\,dx=-\frac{\ln x}{x}+\int x^{-2}\,dx$$
:::

::: diff F461-2-2
نفس M461-2-5 بأس $-3$:
$$v=\frac{x^{-2}}{-2}=-\frac{1}{2x^2}$$
**تصحيح:** المفتاح كتب $\ln x$ بدل $\ln|x|$، وهذا يصح بس لما $x>0$.
:::

::: diff M451-2-3
تكامل **محدد**. احسب الجواب كامل أول (نفس المثال)، بعدين عوّض الحدود في الجواب كله: الأعلى ناقص الأدنى. تذكّر:
$$\ln e=1,\qquad\ln1=0$$
:::

::: box short اختصار للتأكد (بشرطه)
**الشرط:** $n\ne-1$ و$k\ne0$:
$$\int x^n\ln|kx|\,dx=\frac{x^{n+1}}{n+1}\ln|kx|-\frac{x^{n+1}}{(n+1)^2}+C$$
هذا طالع من نفس خطوات التجزئة، فاستخدمه تتأكد من جوابك، واكتب التجزئة في الاختبار. ولو $n=-1$ (يعني $\frac{\ln|kx|}{x}$) ما تحتاج تجزئة أصلًا: عوّض $w=\ln|kx|$:
$$\int\frac{\ln|kx|}{x}\,dx=\frac12\big(\ln|kx|\big)^2+C$$
:::

<div class="h3">$\ln$ لحاله</div>

ما فيه شي مضروب فيه؟ اعتبره مضروب في 1: $u=\ln$ و$dv=dx$، فـ $v=x$، و$x$ تنشطب مع مشتقة $\ln$. مثلًا (تمرين 5):
$$\int\ln|x|\,dx=x\ln|x|-\int x\cdot\frac1x\,dx=x\ln|x|-x+C$$

@example n51e4

::: diff n51x16
$\ln$ مربّع. مشتقته بالسلسلة، وبعد التجزئة يطلع لك $\int\ln|x|\,dx$ (اللي فوق):
$$u=\big(\ln|x|\big)^2,\qquad du=\frac{2\ln|x|}{x}\,dx$$
$$\int\big(\ln|x|\big)^2dx=x\big(\ln|x|\big)^2-2\int\ln|x|\,dx$$
:::
