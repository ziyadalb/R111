@pattern P3

::: box recog
دالة عكسية ($\tan^{-1}$، $\sin^{-1}$، $\sec^{-1}$، $\cosh^{-1}$، $\tanh^{-1}$، $\sech^{-1}$، $\csch^{-1}$) لحالها، أو مضروبة في $x$.
:::

::: box first
$u$ = العكسية، لأن مشتقتها كسر جبري نعرف نتعامل معه. و$dv=dx$ لو لحالها، أو $dv=x\,dx$ لو مضروبة في $x$.
:::

::: box law مشتقات العكسية اللي بتحتاجها
$$\big(\tan^{-1}x\big)'=\frac{1}{1+x^2},\qquad\big(\sin^{-1}x\big)'=\frac{1}{\sqrt{1-x^2}},\qquad\big(\sec^{-1}x\big)'=\frac{1}{x\sqrt{x^2-1}}$$
$$\big(\cosh^{-1}x\big)'=\frac{1}{\sqrt{x^2-1}},\qquad\big(\tanh^{-1}x\big)'=\frac{1}{1-x^2}$$
$$\big(\sech^{-1}x\big)'=\frac{-1}{x\sqrt{1-x^2}},\qquad\big(\csch^{-1}x\big)'=\frac{-1}{|x|\sqrt{1+x^2}}$$
قانون $\sec^{-1}$ هنا حسب المذكرة (ص43)، والباقي من 4.2.
:::

@example M462-2-8

<div class="h3 diffs-title">باقي العكسية لحالها: وش يختلف؟</div>

::: diff M471-2-5
نفس المثال مع $\sin^{-1}x$. التكامل الباقي فيه جذر، فنعوّض اللي تحت الجذر:
$$\int\frac{x\,dx}{\sqrt{1-x^2}},\qquad w=1-x^2,\qquad x\,dx=-\frac{dw}{2}$$
$$x\sin^{-1}x+\sqrt{1-x^2}+C$$
:::

::: diff M451-2-5
نفس M471-2-5 مع $\cosh^{-1}x$، والتعويض $w=x^2-1$ (هنا بدون سالب):
$$x\cosh^{-1}x-\sqrt{x^2-1}+C$$
:::

::: diff n51x9
نفس الفكرة مع $\sec^{-1}x$. بعد الشطب يطلع قانون من 4.2:
$$x\sec^{-1}x-\int\frac{dx}{\sqrt{x^2-1}}=x\sec^{-1}x-\ln\big|x+\sqrt{x^2-1}\big|+C$$
:::

<div class="h3">عكسية مضروبة في $x$</div>

نفس الاختيار ($u$ = العكسية)، بس $dv=x\,dx$ فـ $v=\frac{x^2}{2}$. و$x^2$ هذي تنشطب مع جزء من مشتقة العكسية، ويبقى تكامل تحلّه بتعويض.

@example M472-3-1

::: diff F462-2-2
التكامل الباقي كسر بسطه $x^2$، ودرجته نفس المقام. اكتب البسط بدلالة المقام:
$$\frac{x^2}{1-x^2}=\frac{-(1-x^2)+1}{1-x^2}=-1+\frac{1}{1-x^2}$$
والحد الثاني قانون $\tanh^{-1}$. الجواب:
$$\frac{x^2-1}{2}\tanh^{-1}x+\frac x2+C$$
:::

::: diff n51e6
نفس M472-3-1 مع $\sec^{-1}x$، والتعويض $w=x^2-1$:
$$\frac{x^2}{2}\sec^{-1}x-\frac12\sqrt{x^2-1}+C$$
**تصحيح:** حل المذكرة (ص65) كتب $dv=dx$ و$\sqrt{1-x^2}$، والصحيح $dv=x\,dx$ و$\sqrt{x^2-1}$. جوابه النهائي صحيح.
:::

::: diff n51x10
مع $\csch^{-1}x$: مشتقتها فيها $|x|$. لما $x>0$ يبقى السالب، ويطلع الجذر موجب:
$$\frac{x^2}{2}\csch^{-1}x+\frac12\sqrt{1+x^2}+C$$
ولما $x<0$ تنقلب إشارة الجذر.
:::
