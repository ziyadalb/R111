@pattern P5

::: box recog
تجزئة، بس السؤال مو جاهز لها: جذر داخل الأسّية ($e^{\sqrt x}$)، أو قوة عالية مضروبة في جذر ($x^3\sqrt{x^2-1}$).
:::

::: box first
- **جذر داخل الأسّية:** عوّض أول $w=\sqrt x$، يعني $x=w^2$ و$dx=2w\,dw$. يصير $2\int we^w\,dw$، وهذا النمط 1.
- **قوة مع جذر:** قسّم القوة. خل مع الجذر الجزء اللي هو مشتقة اللي تحت الجذر (ناقصها ثابت)، وهذا يصير $dv$. والباقي $u$.
:::

@example n51x15

::: diff n51x17
$\sqrt{x^2-1}$ لحاله ما نعرف نكامله، بس $x\sqrt{x^2-1}$ نعرف (فيه مشتقة الداخل). فنقسم القوة:
$$x^3\sqrt{x^2-1}=x^2\cdot x\sqrt{x^2-1},\qquad u=x^2,\qquad dv=x\sqrt{x^2-1}\,dx$$
$$v=\frac13\big(x^2-1\big)^{3/2}$$
:::

::: diff n51x18
نفس تمرين 17. مشتقة $x^4+2$ هي $4x^3$، فنخلي $x^3$ مع الجذر:
$$x^7\sqrt{x^4+2}=x^4\cdot x^3\sqrt{x^4+2},\qquad u=x^4,\qquad v=\frac16\big(x^4+2\big)^{3/2}$$
:::

::: box note قبل أي تجزئة
شيك أول: الداخل ومشتقته موجودين؟ إذا إيه، تعويض مباشر يكفي ويحوّل السؤال لقوى، مثل 4.1 و4.2. التجزئة لما التعويض لحاله ما يخلّص.
:::
