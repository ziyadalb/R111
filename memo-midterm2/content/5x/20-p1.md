# <span class="num">2</span> أنماط 5.1: التكامل بالتجزئة

<p class="lede">خمسة أنماط، وتعرف النمط من نوع الضرب: كثير حدود، أو $\ln$، أو دالة عكسية، أو أسّية. في كل نمط: كيف تعرفه، ومثال كامل من الاختبارات، وأسئلة فهم، ووش يختلف في باقي أسئلته. وتحته أسئلته كلها للتدريب، ولكل سؤال رابط لحله.</p>

@pattern P1

::: box recog كيف تعرفه وأول حركة
**تعرفه:** كثير حدود ($2x+1$ أو $x^2$...) × $\sin$ أو $\cos$ أو $\sinh$ أو $\cosh$.

**أول حركة:** جدول: نشتق كثير الحدود لين يوصل صفر، ونكامل الثاني. وعدد الصفوف = درجة كثير الحدود + 2.
:::

@example M452-2-2

@checks P1

<div class="h3 diffs-title">باقي الأسئلة: وش يختلف؟</div>

::: diff M461-2-4
$\sinh x$ مكان $\cos x$. عمود «نكامل»: $\sinh x$ ثم $\cosh x$ ثم $\sinh x$، **بدون سالب**، لأن تكامل الزائدية ما فيه سالب.
:::

::: diff M462-2-3
نفس M461-2-4 بس $\cosh x$: عمود «نكامل» $\cosh x$ ثم $\sinh x$ ثم $\cosh x$.
:::

::: diff F471-2-2
كثير الحدود درجته 2، فالجدول 4 صفوف (ثلاث أقطار، بإشارات $+$ ثم $-$ ثم $+$). و$\cos3x$ داخلها خطي، فكل تكامل تقسم على 3:
$$\cos3x\;\to\;\frac13\sin3x\;\to\;-\frac19\cos3x\;\to\;-\frac1{27}\sin3x$$
:::

::: diff F451-2-2
نفس F471-2-2 مع $\cosh x$: 4 صفوف، والتكاملات بدون سالب وبدون قسمة.
:::
