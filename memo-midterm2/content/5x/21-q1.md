@pattern Q1

::: box recog
$\sin^nx\cos^mx$، ووحدة من القوتين فردية (حتى لو الثانية صفر أو كسر).
:::

::: box first
احجز واحد من صاحب القوة الفردية. الباقي قوته زوجية، فتحوّله بالمتطابقة. و$u$ = الدالة الثانية.
:::

@example M471-2-3

<div class="h3 diffs-title">باقي أسئلة الفصلي والنهائي: وش يختلف؟</div>

::: diff M461-2-6
نفس المثال بالضبط، بس $u^4$ بدل $u^2$:
$$\int u^4\big(1-u^2\big)^2du=\int\big(u^4-2u^6+u^8\big)du$$
:::

::: diff F452-2-6
هنا قوة $\sin$ هي الفردية، فنحجز $\sin x$ و$u=\cos x$. ومشتقة $\cos$ فيها سالب:
$$\sin x\,dx=-du\quad\Rightarrow\quad-\int\big(1-u^2\big)^2u^6\,du$$
والسالب يتوزع على كل الحدود في الآخر.
:::

::: diff M451-2-4
القوتين فرديات. نحجز من الأصغر ($\cos^3$) عشان الفك أقل:
$$\cos^3x=\big(1-\sin^2x\big)\cos x\quad\Rightarrow\quad\int u^5\big(1-u^2\big)du$$
لو حجزت من $\sin^5$ يطلع الجواب بشكل ثاني والفرق ثابت، بس الجبر أطول.
:::

<div class="h3 diffs-title">من المذكرة: وش يختلف؟</div>

::: diff n52e1-1
$\cos$ لحاله بقوة فردية (يعني $\sin^0$): نفس الشي، نحجز $\cos x$:
$$\cos^3x=\big(1-\sin^2x\big)\cos x\quad\Rightarrow\quad\int\big(1-u^2\big)du$$
:::

::: diff n52e2-2
قوة $\sin$ كسرية ($\frac12$)، بس $\cos$ فردية: نحجز منها. والقوى الكسرية نكاملها عادي:
$$\int u^{1/2}\big(1-u^2\big)du=\int\big(u^{1/2}-u^{5/2}\big)du$$
:::

::: box warn فك المربع صح
$$\big(1-u^2\big)^2=1-2u^2+u^4$$
مو $1-u^4$: التربيع ما يتوزع على الطرح.
:::
