@pattern Q4

::: box recog
$\tan$ لحاله بقوة (مثل $\int\tan^4x\,dx$)، أو $\sec$ لحاله بقوة فردية (مثل $\int\sec^3x\,dx$).
:::

::: box first
- **$\tan^m$:** فك $\tan^2x=\sec^2x-1$ **مرة وحدة**. يطلع حد فيه $\sec^2x$ (تعويض $u=\tan x$)، وحد $\tan^{m-2}$ (كرّر عليه).
- **$\sec^n$ فردية:** تجزئة. $dv=\sec^2x\,dx$ لأن تكاملها $\tan x$، و$u$ = الباقي. بيرجع لك نفس التكامل، فتحله كمعادلة مثل الدوّارة.
:::

@example n52e3-2

::: diff n52x16
$\tan^6$: نفك مرة وحدة، ويطلع لك $\int\tan^4x\,dx$ (المثال اللي فوق):
$$\int\tan^6x\,dx=\frac{\tan^5x}{5}-\int\tan^4x\,dx$$
:::

::: box short قانون التخفيض (من المذكرة)
**الشرط:** $m\ge2$:
$$\int\tan^mx\,dx=\frac{\tan^{m-1}x}{m-1}-\int\tan^{m-2}x\,dx$$
$$\int\cot^mx\,dx=-\frac{\cot^{m-1}x}{m-1}-\int\cot^{m-2}x\,dx$$
هو نفس الفك اللي فوق، مكتوب مرة وحدة.
:::

@example n52e3-1

::: diff n52x15
$\sec^5$: نفس الحركة، و$u=\sec^3x$. ويرجع لك $\int\sec^3x\,dx$ (المثال اللي فوق):
$$4\int\sec^5x\,dx=\sec^3x\tan x+3\int\sec^3x\,dx$$
:::
