@pattern Q5

::: box recog
ضرب $\sin$ و$\cos$ بزاويتين مختلفتين: $\sin7x\cos5x$، $\sin4x\sin3x$، $\cos4x\cos7x$. مشتقة الأولى مو موجودة في الثانية، فالحجز ما ينفع.
:::

::: box law حوّل الضرب لجمع
$$\sin A\cos B=\tfrac12\big[\sin(A-B)+\sin(A+B)\big]$$
$$\sin A\sin B=\tfrac12\big[\cos(A-B)-\cos(A+B)\big]$$
$$\cos A\cos B=\tfrac12\big[\cos(A-B)+\cos(A+B)\big]$$
:::

@example n52e5-1

::: diff n52x10
هنا $A-B$ سالب: $3x-5x=-2x$. و$\sin$ دالة فردية، فالسالب يطلع برّا:
$$\sin(-2x)=-\sin2x$$
:::

::: diff n52e5-2
$\sin$ في $\sin$: بين الحدين **طرح**، وحد الطرح قبل حد الجمع:
$$\sin4x\sin3x=\tfrac12\big[\cos x-\cos7x\big]$$
:::

::: diff n52x11
$A-B=-4x$، بس $\cos$ دالة زوجية، فالسالب يختفي:
$$\cos(-4x)=\cos4x$$
:::
