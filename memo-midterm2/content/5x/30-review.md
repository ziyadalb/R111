# <span class="num">3</span> قبل التدريب: كيف تعرف الطريقة؟ وأخطاء شائعة

<div class="h3">اسأل نفسك بالترتيب</div>

| تشوف في السؤال | الطريقة | النمط |
|---|---|---|
| الداخل ومشتقته موجودين | تعويض مباشر | — |
| كثير حدود × ($e^{kx}$ أو $\sin$ أو $\cos$ أو $\sinh$ أو $\cosh$ أو $\sec^2$) | تجزئة، و$u$ = كثير الحدود | 1 |
| $\ln$ (مع قوة، أو لحاله) | تجزئة، و$u=\ln$ | 2 |
| دالة عكسية (لحالها، أو × $x$) | تجزئة، و$u$ = العكسية | 3 |
| أسّية × $\sin$ أو $\cos$ | تجزئة مرتين (الدوّارة) | 4 |
| أسّية × $\sinh$ أو $\cosh$ | التعريف، بدون تجزئة | 4 |
| $e^{\sqrt x}$، أو قوة عالية × جذر | تعويض أو تقسيم القوة، بعدين تجزئة | 5 |
| قوى $\sin$ و$\cos$، وفيه قوة فردية | احجز من الفردية | 6 |
| قوى $\sin$ و$\cos$، وكلها زوجية | خفض القوة | 7 |
| $\tan$ مع $\sec$ (أو $\cot$ مع $\csc$) | احجز $\sec^2$ أو $\sec\tan$ | 8 |
| $\tan$ لحاله، أو $\sec$ لحاله | فك $\tan^2$، أو تجزئة لـ $\sec$ | 9 |
| $\sin$ و$\cos$ بزاويتين مختلفتين | الضرب يصير جمع | 10 |

<div class="h3">أخطاء شائعة: شيك عليها في كل حل</div>

| الغلط | الصح |
|---|---|
| تنسى توزّع السالب اللي قدّام $\int v\,du$ | السالب يضرب القوس كله |
| $\int\sin x\,dx=\cos x$ | $-\cos x$. أما $\int\sinh x\,dx=\cosh x$ بدون سالب |
| $\int\sin3x\,dx=-\cos3x$ | $-\frac{\cos3x}{3}$: اقسم على معامل $x$ |
| تكامل $x^{-3}$ تكتبه $x^{-2}$ | $\frac{x^{-2}}{-2}$: اقسم على الأس الجديد بإشارته |
| في الدوّارة تبدّل الاختيار في المرة الثانية | الأسّية $dv$ في المرتين |
| تنسى $I$ لما تنقله للجهة الثانية | $I+\frac14I=\frac54I$، بعدين اقسم |
| تشيل $\lvert x\rvert$ من $\ln\lvert x\rvert$ | خلها إذا السؤال فيه قيمة مطلقة |
| $(1-u^2)^2=1-u^4$ | $1-2u^2+u^4$ |
| $du=\sin x\,dx$ لما $u=\cos x$ | $du=-\sin x\,dx$، والسالب يطلع برّا التكامل |
| تحجز من قوة زوجية | احجز من الفردية، أو $\sec^2$ لما $\sec$ زوجية |
| $\sin^2x=\frac{1+\cos2x}{2}$ | $\sin^2$ بالطرح، و$\cos^2$ بالجمع |
| $\sin(-2x)=\sin2x$ | $\sin$ فردية: $-\sin2x$. أما $\cos(-2x)=\cos2x$ |

<div class="h3">ورقة المراجعة</div>

::: box law 5.1 التجزئة
$$\int u\,dv=uv-\int v\,du$$
ترتيب اختيار $u$: لوغاريتم، بعدين عكسية، بعدين كثير حدود، وآخر شي الأسّية والمثلثية والزائدية.
:::

::: box steps أول حركة لكل نمط
1. **كثير حدود × دالة:** $u$ = كثير الحدود، وجزّئ بعدد درجته (أو بالجدول).
2. **$\ln$:** $u=\ln$، و$dv$ = القوة أو $dx$.
3. **عكسية:** $u$ = العكسية، والتكامل الباقي بتعويض أو بقانون.
4. **أسّية × $\sin$ أو $\cos$:** الأسّية $dv$ مرتين، وحل المعادلة لـ $I$. **أسّية × زائدية:** التعريف.
5. **مو جاهز:** عوّض أو قسّم القوة، بعدين جزّئ.
6. **قوة فردية في $\sin$ أو $\cos$:** احجز واحد منها، والباقي بـ $1-(\dots)^2$.
7. **كلها زوجية:** خفّض القوة، والزاوية تتضاعف.
8. **$\tan$ و$\sec$:** $\sec$ زوجية: احجز $\sec^2$. $\tan$ فردية: احجز $\sec\tan$.
9. **$\tan^m$ لحاله:** فك $\tan^2=\sec^2-1$ وكرّر. **$\sec^n$ فردية:** تجزئة، و$dv=\sec^2x\,dx$.
10. **زوايا مختلفة:** حوّل الضرب لجمع.
:::

::: box law 5.2 المتطابقات
$$\sin^2x=1-\cos^2x,\qquad\sec^2x=1+\tan^2x,\qquad\csc^2x=1+\cot^2x$$
$$\sin^2x=\frac{1-\cos2x}{2},\qquad\cos^2x=\frac{1+\cos2x}{2}$$
$$\sin A\cos B=\tfrac12\big[\sin(A-B)+\sin(A+B)\big]$$
$$\sin A\sin B=\tfrac12\big[\cos(A-B)-\cos(A+B)\big],\qquad\cos A\cos B=\tfrac12\big[\cos(A-B)+\cos(A+B)\big]$$
:::
