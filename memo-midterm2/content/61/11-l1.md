# <span class="num">2</span> الأنماط الأربعة

<p class="lede">كل سؤال في 6.1 واحد من أربعة أنماط، وتعرفه من الصورة اللي تطلع لما تعوّض. النمط 1 هو الأساس، والثلاثة الباقية تحوّل السؤال للنمط 1.</p>

::: box recog كيف تعرفه وأول حركة
**تعرفه:** كسر، ولما تعوّض يطلع $\frac00$ أو $\frac\infty\infty$.

**أول حركة:** لوبيتال: اشتق البسط لحاله والمقام لحاله، وعوّض مرة ثانية. وكرّر لين تنحسم.
:::

<div class="h3 diffs-title">باقي الأسئلة: وش يختلف؟</div>

::: diff F462-3-1
بسّط قبل لوبيتال: $x$ عامل مشترك فوق وتحت، اختصره:
$$\frac{x-xe^x}{x+2xe^x}=\frac{1-e^x}{1+2e^x}$$
بعدها لوبيتال مرة وحدة تكفي، والجواب $-\frac12$.
:::

::: diff n61e1-3
الجواب ممكن يطلع $\infty$، وهذا جواب صحيح:
$$\lim_{x\to\infty}\frac{x}{\ln x}=\lim_{x\to\infty}\frac{1}{1/x}=\lim_{x\to\infty}x=\infty$$
:::

::: diff n61x2
البسط تكامل حده الأعلى $x$. مشتقته بالنظرية الأساسية: حط $x$ مكان $t$:
$$\frac{d}{dx}\int_0^x\sin(t^2)\,dt=\sin(x^2)$$
:::

::: diff n61x3
بعد لوبيتال مرة صارت الصورة $\frac01$، وهذي محسومة: الجواب $0$. لو كمّلت لوبيتال يطلع 2، وهذا غلط.
:::
