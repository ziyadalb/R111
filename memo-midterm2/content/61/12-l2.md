::: box recog كيف تعرفه وأول حركة
**تعرفه:** ضرب، واحد يروح لـ $0$ والثاني لـ $\infty$.

**أول حركة:** حوّله لكسر: نزّل واحد منهم تحت كمقلوب، فيصير $\frac00$ أو $\frac\infty\infty$، بعدين لوبيتال.
:::

::: box alg مين ينزل تحت؟
خل $\ln$ فوق دايم (مشتقته سهلة)، ونزّل القوة أو الأسّية تحت كمقلوب:
$$e^{-x^3}=\frac{1}{e^{x^3}},\qquad5^{-x}=\frac{1}{5^x},\qquad x^2=\frac{1}{x^{-2}},\qquad x=\frac{1}{1/x}$$
:::
