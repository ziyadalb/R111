@pattern L4

::: box recog كيف تعرفه وأول حركة
**تعرفه:** المتغير في الأس، والصورة $1^\infty$ أو $\infty^0$ أو $0^0$.

**أول حركة:** اكتبها أسّية: $a^b=e^{b\ln a}$. احسب نهاية الأس $b\ln a$ لحاله (غالبًا $0\cdot\infty$، يعني النمط 2). والجواب $e$ أس هالنهاية.
:::

::: box why ليش $e$ و$\ln$؟
$\ln$ ينزّل الأس قدّام كضرب: $\ln a^b=b\ln a$. و$e$ و$\ln$ يلغون بعض: $e^{\ln a}=a$. فبدل قوة صعبة، صار عندك ضرب نعرف نحوّله لكسر.

وليش $1^\infty$ غير معيّنة؟ لأن الأساس **يقرّب** من 1 بس مو 1 بالضبط، والأس يكبر. سباق بين الاثنين، والنتيجة ممكن تطلع أي رقم.
:::

::: box warn نهاية الأس مو هي الجواب
لو نهاية الأس طلعت $L$، الجواب $e^L$. في F472-3-1 نهاية الأس 8، والجواب $e^8$ مو 8. ولو $L=0$، الجواب $e^0=1$.
:::

@example F472-3-1

<div class="h3 diffs-title">باقي الأسئلة: وش يختلف؟</div>

::: diff F471-3-1
الصورة $\infty^0$، والأس يطلع كسر جاهز:
$$x^{\frac1x}=e^{\frac{\ln x}{x}},\qquad\lim_{x\to\infty}\frac{\ln x}{x}=\lim_{x\to\infty}\frac{1/x}{1}=0$$
فالجواب $e^0=1$.
:::

::: diff n61e4-1
الصورة $0^0$. الأس $x\ln x$ صورته $0\cdot(-\infty)$، فنخلي $\ln x$ فوق:
$$x\ln x=\frac{\ln x}{1/x}\to0,\qquad\lim_{x\to0^+}x^x=e^0=1$$
:::

::: diff n61x15
$\cot x=\frac{1}{\tan x}$، فالأس يصير كسر مباشرة:
$$\cot x\,\ln(1+x)=\frac{\ln(1+x)}{\tan x}\qquad\Big(\frac00\Big)$$
:::

::: diff n61x16
من جهة وحدة: $x\to1^-$ يخلي الأس $\frac{1}{x-1}\to-\infty$. الصورة $1^{-\infty}$، وتنحل بنفس الطريقة:
$$x^{\frac{1}{x-1}}=e^{\frac{\ln x}{x-1}},\qquad\lim_{x\to1^-}\frac{\ln x}{x-1}=1$$
:::

::: box more إذا احتجت: طريقة المذكرة
المذكرة تكتب $y=(\dots)$، وتاخذ $\ln|y|$، وتحسب نهايته، وبعدين $\lim y=e^{L}$. هي نفس الخطوات بالضبط، بس بأسماء ثانية.
:::
