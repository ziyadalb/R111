# <span class="num">3</span> قبل التدريب: كيف تعرف الطريقة؟ وأخطاء شائعة

<div class="h3">اسأل نفسك: وش طلع لما عوّضت؟</div>

| طلع لك | وش تسوي | النمط |
|---|---|---|
| رقم | هذا الجواب | الأساس |
| $\frac00$ أو $\frac\infty\infty$ | لوبيتال | 1 |
| $0\cdot\infty$ | نزّل واحد تحت كمقلوب، بعدين لوبيتال | 2 |
| $\infty-\infty$ | وحّد المقامات، أو طلّع عامل مشترك | 3 |
| $1^\infty$ أو $\infty^0$ أو $0^0$ | $a^b=e^{b\ln a}$، والجواب $e^L$ | 4 |

<div class="h3">أخطاء شائعة: شيك عليها في كل حل</div>

| الغلط | الصح |
|---|---|
| تشتق الكسر بقانون القسمة | البسط لحاله والمقام لحاله |
| تكمل لوبيتال بعد ما انحسمت الصورة | عوّض بعد كل خطوة، ووقف لما يطلع جواب محسوم |
| لوبيتال على ضرب أو طرح أو قوة | حوّلها لكسر أول |
| في الطرح تشتق كل حد لحاله | وحّد المقامات أول |
| نهاية الأس هي الجواب | الجواب $e^L$ |
| $1^\infty=1$ | غير معيّنة: الأساس يقرّب من 1 بس |
| $\big(e^{x^3}\big)'=e^{x^3}$ | $e^{x^3}\cdot3x^2$: لا تنسى مشتقة الداخل |
| $\big(\frac1x\big)'=\frac{1}{x^2}$ | $-\frac{1}{x^2}$ |
| $\big(5^x\big)'=x\,5^{x-1}$ | $5^x\ln5$ |
| تترك كسر داخل كسر | اضرب فوق وتحت في المقام الصغير |

<div class="h3">ورقة المراجعة</div>

::: box law كل صورة وحركتها
- **$\frac00$ و$\frac\infty\infty$:** $\lim\frac fg=\lim\frac{f'}{g'}$، والبسط والمقام كل واحد لحاله.
- **$0\cdot\infty$:** $f\cdot g=\frac{f}{1/g}$، و$\ln$ يبقى فوق.
- **$\infty-\infty$:** مقام مشترك، أو عامل مشترك.
- **$1^\infty$ و$\infty^0$ و$0^0$:** $a^b=e^{b\ln a}$. ولو $b\ln a\to L$، الجواب $e^L$.
:::
