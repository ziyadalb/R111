# التدريب

<p class="lede">{{practice}} سؤال: كل أسئلة الاختبارات ({{past}})، وكل مسائل المذكرة ({{notes}}). مرتبة حسب النمط، ولكل سؤال تلميح وحل كامل.</p>

::: box use طريقة التدريب
1. حل سؤال واحد كل مرة. عوّض أول، واكتب الصورة قبل أي شي.
2. علقت؟ اضغط «تلميح». بعد ما تخلص، اضغط «الحل» وقارن.
3. الدائرتين تحت كل سؤال للمتابعة: علّم الأولى لما تحله لحالك، والثانية لما تحتاج تعيده.
4. لا تنتقل للنمط اللي بعده قبل ما تحل سؤالين منه لحالك.
:::
