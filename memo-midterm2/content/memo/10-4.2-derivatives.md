# <span class="secno">4.2</span>الدوال الزائدية العكسية: المشتقات

::: box first قبل أي سؤال: ثلاث أسئلة
1. وش يبي السؤال؟ مشتقة، تكامل، ولا نهاية.
2. وش العملية اللي برّا؟ جمع، ضرب، قسمة، ولا دالة داخلها دالة.
3. وش الحركة اللي تحوّله لشي أعرفه؟ هنا تفتح النمط المناسب.
:::

السؤال الأول في كل نموذج مشتقة (12 سؤال). دايم دالة زائدية أو زائدية عكسية، وداخلها دالة ثانية.

::: box warn
$\sinh^{-1}x$ يعني **الدالة العكسية** (اللي ترجّعك من $\sinh$)، مو المقلوب:
$$\sinh^{-1}x\ne\frac{1}{\sinh x}$$
المقلوب اسمه $\csch x$. ونفس الكلام لكل الدوال العكسية هنا.
:::

## القوانين اللي لازم تكون جاهزة

$u$ هو الداخل، و$u'$ مشتقته. كل قانون مضروب في $u'$، وهذي قاعدة السلسلة. مذكرة المقرر كاتبة نفس القوانين بـ $f(x)$ مكان $u$.

<div class="h3">الدوال الزائدية (من 4.1، وتجي معها في نفس السؤال)</div>

$$(\sinh u)'=\cosh u\cdot u'\qquad(\cosh u)'=\sinh u\cdot u'$$
$$(\tanh u)'=\sech^2u\cdot u'\qquad(\coth u)'=-\csch^2u\cdot u'$$
$$(\sech u)'=-\sech u\,\tanh u\cdot u'$$
$$(\csch u)'=-\csch u\,\coth u\cdot u'$$

::: box warn الفرق عن المثلثية
- $\cosh$ مشتقتها $\sinh$ **بدون سالب** (بعكس $\cos$).
- $\sech$ مشتقتها **فيها سالب** (بعكس $\sec$).
- الباقي نفس نمط المثلثية.
:::

<div class="h3">الدوال الزائدية العكسية (4.2) مع شروطها</div>

$$(\sinh^{-1}u)'=\frac{u'}{\sqrt{1+u^2}}$$
$$(\cosh^{-1}u)'=\frac{u'}{\sqrt{u^2-1}},\qquad u>1$$
$$(\tanh^{-1}u)'=\frac{u'}{1-u^2},\qquad |u|<1$$
$$(\coth^{-1}u)'=\frac{u'}{1-u^2},\qquad |u|>1$$
$$(\sech^{-1}u)'=\frac{-u'}{u\sqrt{1-u^2}},\qquad 0<u<1$$
$$(\csch^{-1}u)'=\frac{-u'}{|u|\sqrt{1+u^2}},\qquad u\ne0$$

::: box short عشان تحفظها أسرع
- $\sinh^{-1}$: جمع تحت الجذر. $\cosh^{-1}$: طرح ($u^2-1$).
- $\tanh^{-1}$ و$\coth^{-1}$: نفس القانون بالضبط، بدون جذر. الفرق في الشرط بس.
- $\sech^{-1}$ و$\csch^{-1}$: فيهم سالب، و$u$ مضروبة برّا الجذر، و$\csch^{-1}$ فيه $|u|$.
:::

::: box fix تصحيح مهم: قانون $\coth^{-1}$
مذكرة المقرر (ص58) كاتبة قانون $\coth^{-1}$ بسالب زيادة، ونفس الغلطة طلعت في مفتاح M451-1-2. الصحيح نفس قانون $\tanh^{-1}$:
$$\frac{d}{dx}\coth^{-1}u=\frac{u'}{1-u^2}$$
ليش؟ من الصيغة اللوغاريتمية (المذكرة ص57):
$$\coth^{-1}u=\tfrac12\ln\frac{u+1}{u-1}$$
$$\frac{d}{du}\coth^{-1}u=\tfrac12\Big(\frac{1}{u+1}-\frac{1}{u-1}\Big)=\tfrac12\cdot\frac{-2}{u^2-1}=\frac{1}{1-u^2}$$
القيمة تطلع سالبة لأن $1-u^2<0$ لما $|u|>1$. هذا من المقام نفسه، فما نضيف سالب ثاني.
:::

## النمط: دالة داخلها دالة (قاعدة السلسلة)

::: box recog
$y$ حد أو حدين، وكل حد دالة زائدية أو زائدية عكسية، وداخلها شي مو $x$ لحاله: $3x^2$، $\sqrt x$، $e^{5x}$، $\sin x$، $\ln|x+1|$.
:::

::: box steps
1. قسّم على الجمع: كل حد تشتقه لحاله. ليش؟ مشتقة المجموع = مجموع المشتقات.
2. في كل حد حدّد الخارج (اسم الدالة) والداخل $u$. ليش؟ عشان تختار القانون الصح.
3. اكتب $u'$ على جنب قبل أي شي. ليش؟ أغلب الأخطاء من نسيان مشتقة الداخل.
4. طبّق القانون: الداخل يبقى زي ما هو، وتضرب في $u'$.
5. بسّط: ربّع $u$ داخل الجذر، واشطب العوامل المشتركة.
6. للدوال العكسية: شيك على شرط المجال.
:::

@example M451-1-1

::: box alg تذكير جبر: الشطب
نشطب **عامل** مضروب في البسط كله وفي المقام كله، مو حد من جمع. هنا 2 عامل فوق وتحت، فنشطبه:
$$\frac{-2}{2x\sqrt{1-4x^2}}=\frac{-1}{x\sqrt{1-4x^2}}$$
لكن هنا ما نقدر نشطب $x$، لأنه في حد واحد بس من البسط. نقسم كل حد:
$$\frac{x+2}{x}=1+\frac2x$$
:::

<div class="h3 diffs-title">باقي أسئلة النمط: وش يختلف؟</div>

<div class="h3">نفس المثال بأرقام ثانية</div>

::: diff M452-1-1
$\tanh$ مشتقتها $\sech^2$، والداخل $2x^3$ مشتقته $6x^2$. و$\sech^{-1}(3x)$ نفس المثال بالضبط:
$$\frac{-3}{3x\sqrt{1-9x^2}}=\frac{-1}{x\sqrt{1-9x^2}}$$
:::

<div class="h3">الداخل جذر أو أسّية أو لوغاريتم</div>

::: diff M461-1-2
الداخل $\sqrt x$: اكتب مشتقته ومربعه:
$$u'=\frac{1}{2\sqrt x},\qquad u^2=x$$
و$\coth$ مشتقتها $-\csch^2$.
:::

::: diff M471-1-1
داخل $\sinh$ جذر. مشتقته = مشتقة اللي تحته على ضعف الجذر:
$$\big(\sqrt{x^2+1}\big)'=\frac{2x}{2\sqrt{x^2+1}}=\frac{x}{\sqrt{x^2+1}}$$
وداخل $\cosh^{-1}$ هو $e^x$، ومربعه $e^{2x}$. الشرط $e^x>1$ يعني $x>0$.
:::

::: diff M472-1-1
دالة وحدة، والداخل لوغاريتم:
$$u=\ln|x+1|,\qquad u'=\frac{1}{x+1}$$
لا تشتق $\ln$ اللي داخل الجذر في القانون؛ هو $u$ نفسه.
:::

::: diff M461-1-1
داخل $\csch$ هو $\frac2x$ ومشتقته سالبة، ومشتقة $\csch$ فيها سالب. سالب في سالب = موجب:
$$-\csch u\coth u\cdot\Big(-\frac{2}{x^2}\Big)=\frac{2}{x^2}\csch u\coth u$$
وفي $\tanh^{-1}(e^{5x})$: مربع الداخل $e^{10x}$، والشرط $e^{5x}<1$ يعني $x<0$.
:::

<div class="h3">بعد القانون فيه تبسيط</div>

::: diff M471-1-2
بعد قانون $\tanh^{-1}$ يطلع لك هذا، فاستخدم الهوية $1-\sin^2x=\cos^2x$:
$$\frac{\cos x}{1-\sin^2x}=\frac{\cos x}{\cos^2x}=\sec x$$
و$\sech$ مشتقتها فيها سالب.
:::

::: diff M462-1-2
قانون $\coth^{-1}$ يعطي كسر داخل كسر. اضرب فوق وتحت في 9:
$$\frac{x^2}{1-\frac{x^6}{9}}=\frac{9x^2}{9-x^6}$$
:::

::: diff M472-1-2
قانون $\csch^{-1}$ فيه $|u|$. الداخل جذر والجذر موجب، فـ $|u|=u$. وجذر في نفسه يعطي اللي تحته:
$$\sqrt{x+2}\cdot\sqrt{x+2}=x+2$$
:::

<div class="h3">طبقة القوة: أس فوق الدالة</div>

$\tanh^2v$ معناها $(\tanh v)^2$. القوة هي أبعد طبقة، فنبدأ فيها، وكل طبقة تعطي عامل:
$$\frac{d}{dx}\big(\tanh v\big)^2=2\tanh v\cdot\sech^2v\cdot v'$$
الترتيب من برّا لجوّا: القوة، بعدين الدالة، بعدين الداخل.

::: diff M451-1-2
الحد الثاني ثلاث طبقات. الداخل ومشتقته:
$$v=\sqrt{2x},\qquad v'=\frac{1}{\sqrt{2x}}$$
$$\frac{d}{dx}\tanh^2\sqrt{2x}=\frac{2\tanh\sqrt{2x}\,\sech^2\sqrt{2x}}{\sqrt{2x}}$$
والحد الأول $\coth^{-1}(3x)$ مشتقته بدون سالب (شوف التصحيح فوق):
$$\frac{3}{1-9x^2}$$
:::

::: diff M452-1-2
التكعيب طبقة، والداخل $\frac1x$ ومشتقته $-\frac{1}{x^2}$:
$$\frac{d}{dx}\Big(\sinh\frac1x\Big)^3=3\sinh^2\frac1x\cdot\cosh\frac1x\cdot\Big(-\frac{1}{x^2}\Big)$$
و$\cosh^{-1}\sqrt x$ مثل $\sinh^{-1}\sqrt x$، بس طرح تحت الجذر:
$$\frac{1}{2\sqrt x\,\sqrt{x-1}}$$
:::

<div class="h3">اختصار: $\csch^{-1}$ لمقلوب</div>

::: box short اختصار وشرطه
من تعريف $\csch^{-1}$، لأي $w\ne0$:
$$\csch^{-1}w=\sinh^{-1}\frac1w$$
ينفع لما يكون الداخل مقلوب شي بسيط مثل $\frac2x$: تحوّله لـ $\sinh^{-1}$ وتريّح نفسك من القيمة المطلقة. هذا تعريف بين هالدالتين بالذات؛ لا تحوّل أي دالة عكسية لمقلوب.
:::

::: diff M462-1-1
$$\csch^{-1}\frac2x=\sinh^{-1}\frac x2$$
$$\frac{d}{dx}\sinh^{-1}\frac x2=\frac{\frac12}{\sqrt{1+\frac{x^2}{4}}}=\frac{1}{\sqrt{x^2+4}}$$
والحد الأول: داخل $\coth$ هو $x^{1/3}$، ومشتقته:
$$u'=\tfrac13x^{-2/3}=\frac{1}{3\sqrt[3]{x^2}}$$
**تصحيح:** جواب المفتاح للحد الثاني يصح بس لما $x>0$، لأنه حط $u$ مكان $|u|$. الجواب بالاختصار يصح على الجهتين.
:::
