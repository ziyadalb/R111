# <span class="secno">4.2</span>الدوال الزائدية العكسية: التكاملات

11 سؤال، كلها تنتهي بقانون من قوانين 4.2. السر: **طابق الشكل كامل**. هل فيه جذر؟ هل فيه شي مضروب برّا الجذر؟ جمع ولا طرح؟ أي فرق من هذي يغيّر القانون.

## جدول الأشكال

$a>0$ ثابت، و$u$ هو الشي المربّع. المذكرة كاتبة نفس القوانين بـ $f(x)$، و$du$ عندنا هي $f'(x)\,dx$ عندها.

<div class="h3">جذر لحاله في المقام</div>

$$\int\frac{du}{\sqrt{u^2+a^2}}=\sinh^{-1}\frac ua+C$$
$$\int\frac{du}{\sqrt{u^2-a^2}}=\ln\big|u+\sqrt{u^2-a^2}\big|+C,\qquad|u|>a$$

<div class="h3">بدون جذر، وطرح</div>

$$\int\frac{du}{a^2-u^2}=\frac1a\tanh^{-1}\frac ua+C,\qquad|u|<a$$

<div class="h3">جذر، و$u$ مضروبة برّاه</div>

$$\int\frac{du}{u\sqrt{a^2-u^2}}=-\frac1a\sech^{-1}\frac{|u|}a+C,\qquad0<|u|<a$$
$$\int\frac{du}{u\sqrt{a^2+u^2}}=-\frac1a\csch^{-1}\frac{|u|}a+C,\qquad u\ne0$$

::: box note بدون جذر وجمع؟
هذي مثلثية عكسية، مو زائدية. بتحتاجها في 5.3 و5.4:
$$\int\frac{du}{u^2+a^2}=\frac1a\tan^{-1}\frac ua+C$$
:::

::: box fix ليش كتبنا $\ln$ مكان $\cosh^{-1}$؟
قانون المذكرة $\cosh^{-1}\frac ua$، وشرطه $u>a$ بس. في سؤالين من السابقات (M461-2-2 وM472-3-2) المجال فيه جهة ثانية ($u<-a$)، وهناك $\cosh^{-1}$ ما ينفع. الصيغة اللوغاريتمية تغطي الجهتين، والدليل إن مشتقتها صح:
$$r=\sqrt{u^2-a^2},\qquad\frac{d}{du}\ln|u+r|=\frac{1+\frac ur}{u+r}=\frac{\frac{r+u}{r}}{u+r}=\frac1r$$
ولو أنت في جهة $u>a$ بس، تقدر تكتب $\cosh^{-1}\frac ua$. الفرق بينهم ثابت ($\ln a$) يدخل في $C$.
:::

::: box warn القيمة المطلقة في $\sech^{-1}$ و$\csch^{-1}$
قانون المذكرة نفسه (ص60) فيه $|f(x)|$. ثلاث مفاتيح شالتها (M452-2-4 وM471-2-4 وM472-3-4)، فصار الجواب صحيح لجهة وحدة بس. لا تشيلها إلا إذا $u$ موجب أكيد، مثل $e^{3x}$ أو $5^x$ أو جذر.
:::

::: box steps
1. شوف اللي تحت الجذر (أو في المقام): فيه حد خطي؟ كمّل المربع أول.
2. حدّد $u$ (اللي صار مربّع) و$a$ (جذر الثابت): $25=5^2$ يعني $a=5$، و$2$ يعني $a=\sqrt2$.
3. اكتب $du$، وتأكد إن السؤال كله صار بـ $u$ وما بقى $x$. لا تكمل بنصف تعويض.
4. طابق مع الجدول، وطبّق، وارجع لـ $x$.
5. اكتب الشرط: وين الجواب صحيح؟
:::

## النمط 1: إكمال المربع تحت الجذر

::: box recog
جذر لحاله في المقام، وتحته $x^2+bx+c$ (فيه حد خطي)، وما فيه شي مضروب برّا الجذر.
:::

::: box alg تذكير جبر: إكمال المربع
خذ نص معامل $x$، وربّعه، وأضفه واطرحه:
$$x^2+6x+13=(x^2+6x+9)+13-9=(x+3)^2+4$$
والإشارة اللي تطلع بعد الإكمال (جمع أو طرح) هي اللي تختار القانون.
:::

@example M452-2-7

<div class="h3 diffs-title">باقي أسئلة النمط: وش يختلف؟</div>

::: diff M462-2-2
نفس المثال. نص 2 هو 1، ومربعه 1:
$$x^2+2x+10=(x+1)^2+9,\qquad a=3$$
:::

::: diff M461-2-2
بعد الإكمال يطلع **طرح**، فالقانون غير، والـ 3 تطلع برّا:
$$x^2+6x-16=(x+3)^2-25,\qquad a=5$$
$$3\int\frac{du}{\sqrt{u^2-5^2}}=3\ln\big|u+\sqrt{u^2-25}\big|+C$$
**تصحيح:** المفتاح كتب $3\cosh^{-1}\frac{x+3}{5}$، وهذا يصح بس لما $x>2$. السؤال يسمح بـ $x<-8$ بعد.
:::

## النمط 2: المربع سالب، و$(x-c)$ مضروب برّا الجذر

::: box recog
تحت الجذر معامل $x^2$ **سالب**، وبرّا الجذر $(x-c)$ مضروب في المقام. بعد الإكمال يطلع $(x-c)$ نفسه، فيصير الشكل $\frac{du}{u\sqrt{a^2-u^2}}$، يعني $\sech^{-1}$.
:::

::: box alg تذكير جبر: الإكمال لما معامل $x^2$ سالب
طلّع السالب من حدود $x$ أول، وكمّل داخل القوس. اللي تضيفه داخل القوس يطلع برّا **بإشارة معكوسة**، لأن القوس مضروب في سالب:
$$7-x^2+6x=7-(x^2-6x)=7-(x^2-6x+9)+9=16-(x-3)^2$$
:::

@example M471-2-4

<div class="h3 diffs-title">باقي أسئلة النمط: وش يختلف؟</div>

::: diff M472-3-4
نفس المثال. انتبه إن $a^2=2$ يعني $a=\sqrt2$:
$$-x^2+4x-2=-(x^2-4x+4)-2+4=2-(x-2)^2$$
$$-\frac{1}{\sqrt2}\sech^{-1}\frac{|x-2|}{\sqrt2}+C$$
:::

## النمط 3: الداخل ومشتقته موجودين

::: box recog
تشوف دالة ومشتقتها مضروبة في $dx$: مثل $\sin x\,dx$ مع $\cos x$، أو $\frac{dx}{x}$ مع $\ln|x|$. عوّض الداخل مباشرة.
:::

@example M451-2-7

<div class="h3 diffs-title">باقي أسئلة النمط: وش يختلف؟</div>

::: diff M472-3-2
$\frac{dx}{x}$ هي مشتقة $\ln|x|$:
$$u=\ln|x|,\qquad du=\frac{dx}{x}$$
$$\int\frac{du}{\sqrt{u^2-1}}=\ln\big|u+\sqrt{u^2-1}\big|+C$$
**تصحيح:** المفتاح كتب $\cosh^{-1}(\ln|x|)$، وهذا يصح بس لما $\ln|x|>1$. السؤال يسمح بـ $\ln|x|<-1$ بعد.
:::

## النمط 4: عوّض الأسّية أو الجذر، واكتب $dx$ كامل

::: box why ليش ينجح؟
الأسّية بدون مشتقة ظاهرة؟ لا تقول التعويض مستحيل. لما تكتب $dx$ كامل بدلالة $u$، التفاضل نفسه يصنع العامل اللي تحتاجه، أو يشطب العامل الزايد.
:::

@example M462-2-7

<div class="h3 diffs-title">باقي أسئلة النمط: وش يختلف؟</div>

::: diff M471-2-2
نفس المثال بأساس 5. مشتقة $5^x$ فيها $\ln5$:
$$u=5^x,\qquad dx=\frac{du}{u\ln5}$$
$$-\frac{1}{\ln5}\csch^{-1}\big(5^x\big)+C$$
:::

::: diff M452-2-4
$u=x^3$، والسؤال فيه $\frac{dx}{x}$. اضرب فوق وتحت في $x^2$:
$$\frac{dx}{x}=\frac{x^2\,dx}{x^3}=\frac{du}{3u}$$
و$x^3$ ممكن يكون سالب، فلازم $|u|$:
$$-\frac{1}{15}\csch^{-1}\frac{|x|^3}{5}+C$$
**تصحيح:** المفتاح كتب $\csch^{-1}\frac{x^3}{5}$ بدون قيمة مطلقة، وهذا يصح بس لما $x>0$.
:::

::: diff M451-2-2
هنا التعويض **يشطب** العامل الزايد بدل ما يصنعه:
$$u=\sqrt x,\qquad dx=2u\,du$$
$$\int\frac{2u\,du}{u\sqrt{1+u^2}}=2\int\frac{du}{\sqrt{1+u^2}}=2\sinh^{-1}\sqrt x+C$$
:::
