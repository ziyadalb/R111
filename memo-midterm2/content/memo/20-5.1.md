# <span class="secno">5.1</span>التكامل بالتجزئة

$$\int u\,dv=uv-\int v\,du$$

الفكرة: نشتق جزء يصير أبسط ($u$)، ونكامل جزء نعرف نكامله ($dv$). في السابقات 11 سؤال في أربع حالات.

::: box recog متى تجزّئ؟
ضرب نوعين مختلفين، **وما فيه** تعويض بسيط يحلّه (يعني مشتقة الداخل مو موجودة). وجود ضرب لحاله ما يعني تجزئة.
:::

::: box law مين تختار $u$ (اللي تشتقه)؟
| السؤال | تشتق | ليش؟ |
|---|---|---|
| كثير حدود × $\cos$ أو $\sinh$ أو $\cosh$ | كثير الحدود | مشتقته تصير ثابت |
| قوة × $\ln$ | $\ln$ | مشتقته $\frac1x$ تمسحه |
| دالة عكسية لحالها أو × $x$ | العكسية | مشتقتها كسر جبري |
:::

::: box steps
1. اكتب الخانات الأربع قبل القانون: $u$ و$dv$، بعدين $du$ و$v$.
2. ركّب: $uv-\int v\,du$.
3. التكامل الجديد لازم يكون أسهل. لو صار أصعب، بدّل اختيارك.
4. كامل الباقي (أحيانًا بتعويض)، وحط $+C$.
:::

## النمط 1: كثير حدود × ($\cos$ أو $\sinh$ أو $\cosh$)

@example M452-2-2

::: box warn الزائدية غير عن المثلثية في الإشارة
تكامل $\sinh$ و$\cosh$ بدون سالب:
$$\int\sinh x\,dx=\cosh x,\qquad\int\cosh x\,dx=\sinh x$$
بعكس المثلثية:
$$\int\sin x\,dx=-\cos x$$
:::

<div class="h3 diffs-title">باقي أسئلة النمط: وش يختلف؟</div>

::: diff M461-2-4
$dv=\sinh x\,dx$ يعني $v=\cosh x$، والتكامل الباقي:
$$\int3\cosh x\,dx=3\sinh x$$
:::

::: diff M462-2-3
$dv=\cosh x\,dx$ يعني $v=\sinh x$، والتكامل الباقي:
$$\int2\sinh x\,dx=2\cosh x$$
:::

## النمط 2: قوة × لوغاريتم

::: box alg تذكير: تكامل القوة واشتقاقها
في الاشتقاق نضرب في الأس القديم وننقصه واحد. في التكامل نزيد الأس واحد ونقسم على الجديد، بشرط الأس مو $-1$:
$$\frac{d}{dx}x^n=nx^{n-1},\qquad\int x^n\,dx=\frac{x^{n+1}}{n+1}+C\quad(n\ne-1)$$
القوة في المقام تصير سالبة فوق، ومشتقة اللوغاريتم ما يأثر فيها الثابت اللي داخله:
$$\frac{1}{x^2}=x^{-2},\qquad\frac{d}{dx}\ln|kx|=\frac1x\quad(k\ne0)$$
:::

@example M471-2-7

<div class="h3 diffs-title">باقي أسئلة النمط: وش يختلف؟</div>

::: diff M452-2-5
نفس المثال والأس 1:
$$v=\frac{x^2}{2},\qquad\frac12\int x\,dx=\frac{x^2}{4}$$
:::

::: diff M461-2-5
الأس سالب، فـ $v$ تطلع سالبة، وانتبه لسالب في سالب:
$$v=\frac{x^{-1}}{-1}=-\frac1x$$
$$-\frac{\ln x}{x}-\int\Big(-\frac1x\Big)\frac1x\,dx=-\frac{\ln x}{x}-\frac1x+C$$
:::

::: diff M451-2-3
تكامل **محدد**: نفس التجزئة، بعدين نعوّض الحدود. تذكّر $\ln e=1$ و$\ln1=0$:
$$\Big[\frac{x^4}{4}\ln x-\frac{x^4}{16}\Big]_1^e=\frac{3e^4}{16}-\Big(-\frac1{16}\Big)=\frac{3e^4+1}{16}$$
:::

::: box short اختصار للتحقق (مو لازم تحفظه)
من نفس خطوات التجزئة:
$$\int x^n\ln|kx|\,dx=\frac{x^{n+1}}{n+1}\ln|kx|-\frac{x^{n+1}}{(n+1)^2}+C$$
**شرطه:** $n\ne-1$ و$k\ne0$. لو $n=-1$ يصير قسمة على صفر والطريقة تختلف. مثال: مع $n=3$ و$k=2$ يطلع جواب M471-2-7 نفسه.
:::

## النمط 3: دالة عكسية لحالها

::: box recog
$\int\tan^{-1}x\,dx$ أو $\int\sin^{-1}x\,dx$ أو $\int\cosh^{-1}x\,dx$: ما فيه ضرب ظاهر! اعتبرها مضروبة في 1. نشتق العكسية ($u$)، ونكامل الواحد ($dv=dx$)، فيطلع $v=x$.
:::

::: box alg تذكير جبر: نوفّر المشتقة الناقصة
لو البسط تقريبًا مشتقة المقام، اضرب واقسم على نفس الثابت. ما غيّرنا السؤال؛ كتبناه بنفس القيمة:
$$\int\frac{x}{1+x^2}\,dx=\frac12\int\frac{2x}{1+x^2}\,dx=\frac12\ln\big(1+x^2\big)$$
:::

@example M462-2-8

<div class="h3 diffs-title">باقي أسئلة النمط: وش يختلف؟</div>

::: diff M471-2-5
$$du=\frac{dx}{\sqrt{1-x^2}}$$
والتكامل الباقي بتعويض $w=1-x^2$:
$$\int\frac{x\,dx}{\sqrt{1-x^2}}=-\sqrt{1-x^2}$$
وناقص في ناقص يطلع زائد:
$$x\sin^{-1}x+\sqrt{1-x^2}+C$$
:::

::: diff M451-2-5
$$du=\frac{dx}{\sqrt{x^2-1}}$$
والتكامل الباقي بتعويض $w=x^2-1$:
$$\int\frac{x\,dx}{\sqrt{x^2-1}}=\sqrt{x^2-1}$$
:::

## النمط 4: دالة عكسية × $x$

::: box recog
عكسية مضروبة في $x$: نشتق العكسية ونكامل $x$. التكامل الباقي يطلع فيه $x$ فوق وجذر تحت، فنكمله بتعويض الداخل.
:::
